# RecallGraph brand handoff

## Approved mark

**Linear Stitch** is the sole primary RecallGraph logo. The approved source remains at `brand/renders/mark-1-linear-stitch.svg`; it is promoted as `public/logo.svg` with only a warm-bone carrier added. Its lineage paths and vermilion stitch geometry are otherwise unchanged.

Use the files as follows:

| Asset | Purpose |
| --- | --- |
| `public/logo.svg` | Sole promoted primary mark; standalone `0 0 64 64` SVG. |
| `public/favicon.svg` | Standalone 16px-scale favicon variant of the same Linear Stitch geometry/concept. |
| `public/logo.png` | Native local 512 × 512 rasterization of `public/logo.svg`; it is neither AI-generated nor upscaled. |
| `brand/brand.json` | Machine-readable brand contract. |
| `brand/tokens.css` | Exact CSS custom-property contract for the production Daylight Forensics workspace. |
| `brand/DESIGN-TOKENS.md` | Usage, accessibility, state, and motion guidance. |

Keep the mark on its warm-bone carrier. On the closure docket or other dark surfaces, retain the carrier. Do not reverse the graphite paths or invent another mark direction.

## Palette and type

Daylight Forensics uses paper canvas (`#F2EFE7`), warm-white evidence (`#FCFBF7`), carbon ink (`#18201E`), registry muted text (`#63706B`), petrol evidence/selection (`#1F5B63`), oxide closure/risk (`#D94A2F`), and one dark docket (`#151B1A`). The mark’s vermilion (`#F05A3C`) is heritage artwork, not a new UI accent. Body and control text use the Avenir Next-led stack; display text uses the Iowan Old Style-led stack. See the token guide for fallbacks and contrast evidence.

## Exploration record

The Fold Stitch and Orbit Stitch SVGs, review page, and review render remain in `brand/` as the exploration paper trail. They are not promoted and should not be used as primary marks.

## Prototype boundary

This handoff preserves the approved Linear Stitch while the production workspace applies the Daylight Forensics token contract. It creates no alternate mark, framework dependency, ICO, or OG image.
